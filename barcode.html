바코드 생성기 · EAN-13 · Code 128

상품에 붙이는 EAN-13·EAN-8 바코드와, 영문·숫자를 담는 Code 128 바코드를 만들어 PNG로 저장합니다. 체크 숫자는 자동으로 계산하고, 이미 있는 번호는 맞는지 검증합니다.

🔒 입력한 내용이 서버로 전송되지 않습니다

주소·와이파이·연락처를 담으려면 바코드가 아니라 QR코드 만들기가 맞습니다. 만든 바코드 그림을 라벨에 넣기 전에 이미지 자르기로 여백을 맞출 수 있습니다.

어느 바코드를 써야 하나

EAN-13 — 마트·편의점·온라인몰에 납품하는 상품 바코드입니다. 숫자 13자리이고, 앞 3자리 880은 한국 상품을 뜻합니다. 번호는 대한상공회의소 유통물류진흥원(GS1 Korea)에 업체 등록을 해야 발급받습니다. 아무 숫자나 만들어 붙이면 스캔은 되지만 다른 회사 상품으로 잡힙니다. 여기서는 발급받은 번호를 그림으로 만드는 용도로 쓰세요.
EAN-8 — 껌·초콜릿처럼 포장이 작은 상품용 8자리입니다.
Code 128 — 숫자뿐 아니라 영문·기호도 담을 수 있어 택배 송장, 자산 관리 스티커, 회원증, 도서관 대출증, 창고 위치 표시에 씁니다. 사내에서만 쓰는 번호라면 등록 없이 마음대로 정하면 됩니다. 한글은 담을 수 없습니다(한글이 필요하면 QR코드).

자주 묻는 질문

입력한 내용이 어디로 보내지나요?

아니요. 바코드는 브라우저 안에서 그려지고 어디로도 보내지 않습니다. 인터넷을 끊어도 동작합니다.

체크 숫자가 뭔가요?

EAN 바코드의 마지막 한 자리는 앞자리들로 계산한 검증용 숫자입니다. 스캐너가 잘못 읽으면 이 숫자가 맞지 않아 걸러집니다. 12자리만 넣으면 자동으로 계산해 붙이고, 13자리를 넣으면 마지막 자리가 맞는지 확인해서 틀리면 알려 드립니다.

스캔이 안 돼요

세 가지를 확인하세요. 첫째, 바코드 양옆의 흰 여백을 잘라내지 않았는지(여백이 없으면 못 읽습니다). 둘째, 인쇄가 너무 작지 않은지 — 굵기를 "인쇄용"으로 두고 실제 크기 3cm 이상으로 인쇄하세요. 셋째, 흐린 잉크젯 출력이나 반짝이는 코팅지는 읽기 어렵습니다.

상품 바코드 번호는 어떻게 받나요?

대한상공회의소 유통물류진흥원에 회원 가입을 하면 업체 코드를 받고, 그 뒤에 상품별 번호를 붙여 13자리를 만듭니다. 이 페이지는 번호를 발급하지 않고, 발급받은 번호를 바코드 그림으로 만들어 줍니다.

Code 128에 한글을 넣고 싶어요

Code 128은 영문·숫자·기본 기호(ASCII)만 담는 규격이라 한글은 들어가지 않습니다. 한글이나 긴 내용이 필요하면 QR코드를 쓰세요.

인쇄할 때 크기는요?

EAN-13의 표준 크기는 가로 37.3mm × 세로 25.9mm이고, 80%~200%까지 줄이거나 키울 수 있습니다. 굵기 6px로 저장한 PNG를 가로 4cm 정도로 인쇄하면 대부분의 스캐너가 읽습니다.
