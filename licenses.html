오픈소스 고지

툴모아는 아래 오픈소스 라이브러리를 사용합니다. 저작권은 각 저작자에게 있으며, 각자의 라이선스 조건에 따라 이용하고 있습니다.

이 라이브러리들은 외부 CDN에서 불러오지 않고 이 사이트 안에 직접 담아 제공합니다. CDN 주소가 바뀌거나 CDN이 멈추면 사이트가 통째로 동작하지 않게 되고, 무엇보다 이용자의 방문 기록이 제3자에게 넘어가기 때문입니다. 그 덕분에 이 사이트는 외부로 나가는 요청이 한 건도 없습니다.

pdf.js

Copyright © Mozilla Foundation — Apache License 2.0
PDF 페이지를 화면에 미리보기로 그리는 데 씁니다. (PDF 나누기 · PDF 회전·삭제 · PDF 합치기)

github.com/mozilla/pdf.js · 라이선스 전문 · 사이트에 담긴 파일: assets/vendor/pdf.min.js, assets/vendor/pdf.worker.min.js

pdf-lib

Copyright © Andrew Dillon — MIT License
PDF를 합치고, 나누고, 페이지를 돌리고 지운 새 파일을 만드는 데 씁니다. (내부적으로 Microsoft의 tslib 도우미 코드를 포함하며, 해당 부분의 저작권은 Microsoft Corporation에 있습니다.)

github.com/Hopding/pdf-lib · 라이선스 전문 · 사이트에 담긴 파일: assets/vendor/pdf-lib.min.js

SheetJS (xlsx)

Copyright © SheetJS LLC — Apache License 2.0
엑셀·CSV·JSON 파일을 읽고 쓰는 데 씁니다. (CSV · JSON · 엑셀 변환)

sheetjs.com · 라이선스 전문 · 사이트에 담긴 파일: assets/vendor/xlsx.full.min.js

QR Code Generator for JavaScript

Copyright © 2009 Kazuhiko Arase — MIT License
QR코드의 검은 칸·흰 칸 배치를 계산하는 데 씁니다. 화면에 그리는 일은 툴모아가 직접 합니다.

github.com/kazuhikoarase/qrcode-generator · 라이선스 전문 · 사이트에 담긴 파일: assets/vendor/qrcode.min.js

'QR Code'는 주식회사 덴소웨이브(DENSO WAVE INCORPORATED)의 등록상표입니다.

직접 만든 부분

ZIP 파일로 묶는 기능(assets/zip.js)은 외부 라이브러리를 쓰지 않고 직접 구현했습니다. 묶는 대상이 PDF·JPG처럼 이미 압축된 파일이라 압축 없이 담기만 하면 되고, 그 정도는 외부 요청 0건을 지키면서 만들 수 있는 분량이었기 때문입니다.

다국어 처리(assets/i18n.js)와 각 도구의 화면·동작도 직접 작성했습니다. 전체 소스는 GitHub 저장소에 공개되어 있습니다.
