각 페이지의 ↺ ↻ 로 돌리고, ✕ 로 삭제 표시를 합니다. 카드를 끌어서 순서를 바꿀 수 있습니다.

여러 PDF를 하나로 합치려면 PDF 합치기를, 페이지만 뽑아내려면 PDF 나누기를 쓰세요.

자주 묻는 질문

스캔한 문서가 옆으로 누워 있는데요.

미리보기를 보면서 해당 페이지의 ↻ 또는 ↺ 를 눌러 바로 세우면 됩니다. 여러 장이 같은 방향이면 위쪽의 "전체 오른쪽/왼쪽" 버튼이 빠릅니다.

회전이 진짜로 저장되나요?

네. 보기만 돌리는 것이 아니라 PDF 파일 자체의 페이지 회전값을 바꿔서 저장하므로, 어떤 프로그램에서 열어도 바로 서 있습니다.

파일이 서버로 올라가나요?

아니요. 미리보기 생성부터 저장까지 전부 브라우저 안에서 이뤄집니다.

페이지가 많으면 느린가요?

미리보기를 만드는 데 잠깐 걸립니다. 100쪽이 넘는 문서는 앞부분부터 순서대로 나타납니다.

원본이 바뀌나요?

바뀌지 않습니다. 항상 새 파일로 저장됩니다.
