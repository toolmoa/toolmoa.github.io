    Why convert SVG to PNG

    SVG is a vector format that never pixelates, but older versions of PowerPoint and Word, social networks, many shop admin panels and email either refuse SVG or render it badly. Exporting a PNG once at the size you need makes the graphic usable everywhere. A 2× or 3× scale stays crisp on high-density (Retina) screens, and transparency is preserved in PNG and WebP. The conversion uses the browser's own SVG renderer, so the result looks exactly as the SVG does on screen.

    SVGs without a size · fonts · external images

    No width/height — the aspect ratio is taken from the viewBox and fitted to the pixel width you choose. Without a viewBox the file is treated as 300×150, so set the pixel size yourself.
    Fonts — text inside an SVG is drawn with the fonts installed on this computer. If the designer's machine had different fonts the shapes will differ; SVGs with text converted to outlines are safe.
    External images and stylesheets — <image href="http://…"> pointing at other files and external CSS are not loaded for security reasons. Images embedded as data URIs inside the SVG do work.

    Why it runs in the browser — unreleased logos and internal diagrams are exactly what gets converted. Nothing is uploaded, and the page works offline once loaded.

    Frequently asked questions

    Is my file uploaded?

    No. The SVG is read, rendered and saved as PNG inside your browser; it works with the internet switched off.

    Edges look blurry or jagged

    At small sizes thin lines fall inside a single pixel and blur. Render at twice the size you will display and let the page or document scale it down — that is what the 2× and 3× scale options are for.

    The transparent background came out white or black

    JPG has no transparency, so transparent areas become white. Choose PNG or WebP to keep transparency. To preview on a dark background, set the background to a custom color.

    Text in the SVG uses the wrong font

    SVG files name fonts but do not contain them, so a missing font is replaced. Convert text to outlines in your drawing program before exporting and it will look the same everywhere.

    What is the maximum size?

    8192 pixels on a side, the limit of what a browser canvas can draw in one piece. For very large print graphics, use the SVG itself.

    Will the PNG be larger than the SVG?

    Usually, yes: an SVG stores shapes, a PNG stores every pixel. On the web keep the SVG wherever possible and convert only where PNG is required. The PNG can be shrunk further with compress image.
