When a watermark is worth it

Contracts, quotes, proposals, course hand-outs — documents meant for a specific recipient. A faint "Confidential" or the recipient's own name across every page tells you where a leaked copy came from and makes people think twice before forwarding it. Writing "for XYZ application only" across a scan of your passport or a bank statement works the same way. Those are exactly the files you should not upload to a random website, which is why this page does the stamping inside your browser and sends nothing anywhere.

Frequently asked questions

Is my PDF uploaded anywhere?

No. The PDF is opened, stamped and saved inside your browser. The page keeps working with the internet switched off. It was built for contracts and ID scans, the files that must not leave your computer.

Does it support my language?

Yes, any script — Korean, Japanese, Arabic, emoji. Instead of embedding a PDF font, the text is drawn exactly as your screen shows it and stamped as an image, so no font files are needed. The one trade-off is that the watermark text cannot be selected or copied in the PDF, which for a watermark is usually what you want.

Can the watermark be removed?

It is a separate image layered on each page, so a PDF editor could pick it out and delete it. For a mark that cannot be separated, convert the pages to images with PDF to image and rebuild the file with image to PDF. Text selection is lost, but the mark becomes part of the page.

What opacity should I use?

15–30% if the document still has to be read. 100% hides whatever is underneath. The preview shows the mark on a blank page, so open the saved file once to check it over the real content.

What about password-protected PDFs?

They cannot be opened. Remove the password and save a copy first. PDFs that merely restrict editing usually work.

Will the file get much bigger?

No. One watermark image is added and every page shares it, so even long documents grow by only tens or hundreds of kilobytes.
